# Package com.eignex.koblas

The koblas linear-algebra API: the [Matrix] / [Vector] containers, the [LinearAlgebra] operation set
(BLAS-1/2/3 plus LU [factor][LinearAlgebra.factor] / [solve][LinearAlgebra.solve]), the portable
[ReferenceLinearAlgebra] backend, the [platformLinearAlgebra] native-backend seam, and the resolved
default backend [koblas].
