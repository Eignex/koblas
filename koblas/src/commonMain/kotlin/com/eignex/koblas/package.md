# Package com.eignex.koblas

The koblas linear-algebra API: the [MatrixView] / [DenseMatrix] and [VectorView] / [DenseVector] /
[SparseVector] containers (all `@Serializable`), the free-function arithmetic over them ([dot], [axpy],
[scale], [addOuter], [matVec], [forEachStored], and the SPD suite [cholesky],
[choleskyDowndateInPlace], [solveSpd], [invertSpd]), and the platform backend id [mathBackend].
